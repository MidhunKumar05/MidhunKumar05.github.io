Eunomia

Rust · Axum · SurrealDB · Next.js · TypeScript · Self-hosted

Eunomia is a personal memory and knowledge assistant — a place to accumulate facts, people, organisations, and context over time, and have an agent reason over it rather than starting from zero in every conversation.

What it does

At its core is an entity/memory graph: people, organisations, locations, and (for working in codebases) repositories, files, and symbols — each with notes attached and relations drawn between them. A vault system scopes that graph per-user or per-team, so a personal knowledge base and a shared one coexist without stepping on each other.

A chat agent sits on top with tool-calling access to that graph plus a recall/search layer over ingested records, so it can look things up, write new memories, and cite its sources rather than hallucinate them. Connectors (Up Bank, PocketAI, and a generic open connector) pull external data in on a schedule, and every mutating action is written to an audit log.

Backend

Rust, Axum, the official SurrealDB SDK — auth, vaults, entities, connectors, chat streaming (SSE), all on one schema.

Database

SurrealDB — graph relations, full-text search, and vector search (MTREE) in one engine.

Frontend

Next.js, TypeScript — dashboard, entity graph, chat, vaults, connectors, settings.

Deployment

Docker Compose — SurrealDB, backend, and frontend, one command to bring up.

Install

Requires git and Docker (with the Compose plugin). Clones the latest release, generates fresh secrets into a .env, and starts the stack.

curl -fsSL https://midhunkumar05.github.io/eunomia/install.sh | bash
Installs into ./eunomia · frontend on :3000 · backend on :8001

Checking for updates

Any client — the app's own self-update check, a script, whatever — can poll GitHub's releases API to see what the current version is:

GET https://api.github.com/repos/Qyrhal/Eunomia/releases/latest

The tag_name field (e.g. v1.1.3) is the current release.

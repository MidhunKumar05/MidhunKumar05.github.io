# midhunkumar05.github.io

GitHub Pages site hosting [Eunomia](https://github.com/Qyrhal/Eunomia): the landing page, docs viewer and installer live in `eunomia/` and are served at https://midhunkumar05.github.io/eunomia/. The root `index.html` redirects there.

Install: `curl -fsSL https://midhunkumar05.github.io/eunomia/install.sh | bash`

`index.yaml` and `charts/` are a Helm chart repository (discordbot) served from the site root.
